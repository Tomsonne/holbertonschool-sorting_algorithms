# holbertonschool-sorting_algorithms

Implémentation d'algorithmes de tri en **C**, avec analyse de leur complexité
(projet Holberton School).

Chaque algorithme occupe un fichier `<n>-<nom>.c` à la racine : tri à bulles,
tri par insertion sur liste doublement chaînée, tri par sélection et tri rapide.
Les fichiers `<n>-O` contiennent la complexité (meilleur, moyen, pire cas) de
l'algorithme correspondant, et les fichiers `<n>-main.c` servent de programmes de
test. `sort.h` regroupe les prototypes et la structure `listint_t` ;
`print_array.c` et `print_list.c` fournissent les fonctions d'affichage.
